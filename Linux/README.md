# what is Linux?
Linux is a open-source, unix-like operating system manages computer hardware, software, files, memory, processes, and users. It provides a secure and stable environment to run applications.

# Navigation Commands
pwd - print current working directory

ls  - list files

ls -l  - Detailed list and folders with permission, size date

ls -la  - Hidden files(.)detailed list show

cd   - Directory change 

cd ..  - move back one level

cd ~   - Go to Home Directory

cd /   - Go to root directory

tree    - directory structure in tree format

clear   - Terminal screen clear

history - executed command list(used commands)
